# 前后端算法对接说明

## 前端已增加的功能

### 用户登录

账户保存在本机数据库。角色分为操作员、技术员、管理员。首次启动须创建管理员；操作员和技术员注册须管理员现场授权。登录后按角色开放对应设置项。监视画面与节点启停不要求登录。连续输错密码会锁定账户。设置保存写入操作审计。

### 报表统计

按时间范围查询检测记录，汇总检测铜板数、有粒子修磨铜板数、修磨完成率和平均修磨节拍，并提供每日检测与修磨、粒子高度分布和班次汇总。支持导出 PDF。

### 系统设置

| 页面 | 内容 |
| --- | --- |
| 设备与通信 | 节点启动与暂停、数据存储、相机节点 / 海康相机 / PLC 状态 |
| 检测与标定 | 相机节点状态、海康实时预览、检测判定、坐标标定 |
| 修磨工艺 | 坐标补偿、现场示教、修磨参数、复检策略 |
| 安全与权限 | 账号管理、登录保护、操作审计 |

## 1. 粒子信息（算法）

算法须提供每颗检出粒子的信息，供前端在扫描图上定位并显示该粒子，不再用铣削路径近似。

建议消息名：`mz_interfaces/ParticleInfo`。与该任务的 `milling/paths` 一并发布。

| 字段 | 含义 |
| --- | --- |
| `task_id` | 与 `milling/paths.task_id` 及扫描帧一致 |
| `frame_id` | 粒子坐标所属扫描帧 |
| `particle_id` | 粒子编号，从 1 起 |
| 范围 | `u_min`、`v_min`、`u_max`、`v_max`（像素），或 `center_u`、`center_v` 加半径 |
| `height_mm` | 单粒子高度，可选 |
| `grade` | 单粒子等级，可选 |
| `path_indexes` | 该粒子对应的 `paths[]` 下标，可选 |

坐标须位于对应 `frame_id` 的 `width`、`height` 之内。

## 2. 修磨启停（后端）

前端在非演示模式下，点击开始、暂停、停止会发布指令。按钮文字不由这次点击直接改变，只跟 `plc/feedback.status_word` 变化。Ctrl+T 演示模式仍只驱动本机动画，不发布本 topic，也不用 PLC 状态改按钮。

消息：`mz_interfaces/MillingCommand`。Topic：`milling/command`。方向：前端 → 后端。可靠队列，保留最近 10 条。

| 字段 | 含义 |
| --- | --- |
| `command` | `1` 启动，`2` 暂停，`3` 停止。没有单独的恢复指令 |
| `task_id` | 已知的 `milling/paths.task_id`。暂停和停止在尚未收到任务号时为 `0`，表示当前正在执行的流程 |

- 启动：操作员点击「开始」时发送。暂停之后再次点击「开始」仍发送 `1`，由后端根据自己是空闲还是已暂停，决定重新开始或从暂停处继续。
- 暂停、停止：按钮当前显示「暂停」时，点击分别发送 `2`、`3`。PLC 或其他方已经启动流程时也可以发。
- 按钮：`status_word` 为拍照完成 `4`、任务执行中 `12`、路径请求 `30`、拍照请求 `40`、换刀中 `50`、换刀完成 `60` 时显示「暂停」。准备就绪、任务暂停、打磨完成等其余状态显示「开始」。例如 PLC 触发拍照后，后端把状态字变为 `40`，按钮随之变为「暂停」。

后端收到后发布 `mz_interfaces/MillingCommandResult`，Topic：`milling/command_result`。

| 字段 | 含义 |
| --- | --- |
| `command` | 对应被处理的 `MillingCommand.command` |
| `task_id` | 对应任务 |
| `accepted` | 是否接受 |
| `message` | 拒绝原因或补充说明；接受时可以为空 |

拒绝只记入日志。按钮是否显示「暂停」仍只看 PLC 状态字。

- 修磨等级、复检条件、未达标处理
