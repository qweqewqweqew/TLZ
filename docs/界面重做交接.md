# 界面重做交接

本文用于约束新界面。功能与控件位置按本文执行。未写入「可以修改」的部分，不改。

主题切换的现有机制保留。界面同时提供深色和浅色两套外观。每个控件都要有对应的两种样式，两套颜色各自成组，切换后不能出现一块区域仍是另一套颜色。配色不必沿用现在的色值，但同一模式下背景、卡片、图像区、文字、按钮必须一起设计，看起来是一套，不能突兀。

## 视觉

可以改颜色、字号、间距和控件尺寸。改的时候遵守下面这些，不再按单个控件来回试。

- 深色一套、浅色一套。控件的底色、边框、文字、悬停、按下、禁用都要成对给出，不能只做其中一种。
- 图像、三维点云、实时画面的底色单独指定，并与周围卡片区分开。深色里画面区可以比卡片更深，浅色里用浅灰，不要和卡片混成一片，也不要突然换成无关的颜色。
- 同一页面只用一套间距。卡片之间留出缝，卡片内部不要出现大块空白。控件高度按内容定，数字和按钮完整可见。
- 少写说明文字。能用标题、数值、状态点表示的，不另加一句解释。
- 正文、数字、次要信息和状态色分开。字号有层级，正文不要小于能看清的尺寸，状态色不能和背景糊在一起。

改界面之前先读 `ui-ux-pro-max` 这个 skill，并用它的检索确定这一页的配色、字号、间距和右侧排布。检索脚本：

`C:/Users/28651/.cursor/skills/ui-ux-pro-max/scripts/search.py`

先写出将要做成的样子，至少包括：深色和浅色的背景、卡片、画面区、主要文字、按钮色；检测与修磨右侧五块怎么摆；哪些文字会删掉。把这个样子交给使用的人确认。确认之前不改代码。确认之后按这个样子一次做完，不在做完后再逐个控件反复调整。

## 不可修改

### 全局位置

这些控件的位置保持现状。外观可以换，但不能换到别的区域。

| 位置 | 保留的控件 |
| --- | --- |
| 顶栏左侧 | 铭准、MZ-VISION |
| 顶栏中间 | 系统名称「阴极铜板粒子检测及修磨系统」 |
| 顶栏右侧 | 设备在线状态、日期时间、报警与事件日志、用户登录 |
| 左侧栏上方 | 四个页面入口，顺序固定：检测与修磨、历史查询、报表统计、系统设置 |
| 左侧栏下方 | 深色 / 浅色切换、当前登录用户 |

登录、日志、设备状态、页面切换、深浅模式的功能保留。新样式可以接受，位置不可以改。

### 检测与修磨的结构

这一页保持左右结构。

- 左侧只放铜板图像画面。
- 右侧只放这些功能，不把它们移到左侧或别的页面：粒子三维点云、实时数据、实时画面、打磨路径、修磨操作按钮。

点选关系保留：在图像上点路径，粒子信息和路径队列一起选中；在路径队列里点，粒子信息跟着选中。

扫描图、路径、进度、PLC 反馈的数据来源不改。粒子三维在算法粒子数据接入前，仍用铣削路径近似。启动、暂停、停止在后端控制接口接入前，仍不向设备下发。

### 历史查询与报表统计

查询、筛选、统计、导出的功能保留，不删字段，不改数据来源。

### 系统设置

顶部四个栏目保留，名称和顺序不变：设备与通信、检测与标定、修磨工艺、安全与权限。

新界面里这四个栏目的内容先置空。现有设置项先不迁入，等确认哪些有用后再做。

## 可以修改

只允许改外观和右侧内部的排布，不允许改上面列出的功能和位置。

| 范围 | 可以改什么 |
| --- | --- |
| 全局控件 | 顶栏、左侧栏、登录、日志、状态、深浅切换的颜色、字号、图标、圆角。位置不动 |
| 检测与修磨左侧 | 图像卡片的边距、标题、工具条样式。图像仍占左侧整列 |
| 检测与修磨右侧 | 粒子三维、实时数据、实时画面、打磨路径、操作按钮的相对位置和尺寸。现在的 2×2 不是最终方案，新排布必须让这些控件同时可见、文字和数字不被裁切 |
| 历史查询 | 列表、筛选、详情的控件样式 |
| 报表统计 | 图表、卡片、表格、按钮的控件样式 |
| 系统设置 | 四个空栏目内部的空白页样式。不恢复旧内容 |

## 检测与修磨右侧

右侧要同时放下五块：

1. 粒子三维点云
2. 实时数据
3. 实时画面
4. 打磨路径
5. 修磨操作按钮

2×2 能放下，但各块高度互相限制，数字和按钮容易被挤。新排布尚未确定。确定前不沿用现有 2×2，也不把其中任何一块移出右侧。
