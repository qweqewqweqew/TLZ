# 设备状态横向布局设计

## 目标

将运行状态面板底部的单个相机状态卡改为一行三等分的设备状态卡，依次显示相机、后端和 PLC。

## 状态来源

- 相机：继续订阅 `camera/status`，保留现有在线、离线和心跳超时后的未知状态。
- 后端：前端每次收到 `plc/feedback` 即标记为在线，不设置反馈超时。
- PLC：直接显示 `PlcFeedback.status_word`；`fault_code != 0` 时显示故障并标红。首次收到反馈前显示未知。

当前接口没有给出 `status_word` 的枚举或位定义，因此界面先显示准确的原始十进制状态值，并在 tooltip 中同时展示十六进制状态字和故障码，不推断未定义的“运行/停止”等语义。

## 布局

“设备状态”标题下使用一张 52px 高的深色卡片。卡片内部是三个等宽单元，相邻单元之间用低对比度竖线分隔。每个单元包含状态圆点、设备名称和右对齐状态文字：

```text
● 相机  未知  |  ● 后端  未知  |  ● PLC  未知
```

绿色表示在线，红色表示离线或故障，青色表示已收到但尚未解释枚举的 PLC 状态，灰色表示未知。
