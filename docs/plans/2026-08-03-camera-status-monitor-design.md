# 相机状态监控设计

## 目标

前端显示相机硬件是否可用，而不是仅判断 ROS 相机节点是否存在。状态显示位于“运行状态”面板的“当前速度”下方。

## 通信设计

新增 `mz_interfaces/CameraStatus` 消息和 `camera/status` topic。传感器端每秒发布一次状态，并使用 Reliable + Transient Local QoS，使后启动的前端能立即拿到最近状态。

消息字段保持最小：

- `connected`：相机 SDK 是否确认连接。
- `camera_id`：已识别的相机标识。
- `message`：连接说明或最近错误。
- `timestamp_ns`：传感器端发布时间。

原有 `ScanResult.is_cam_connect` 暂时保留兼容外部订阅者，但前端不以它作为状态来源。

## 前端状态语义

- 在线：3 秒内收到状态且 `connected=true`。
- 离线：3 秒内收到状态且 `connected=false`。
- 状态未知：启动后尚未收到状态，或超过 3 秒没有更新。

“状态未知”用于覆盖传感器程序停止、ROS 通信中断等无法直接归因于相机硬件的情况，避免误报相机离线。

## 界面

在“当前速度”下方增加“设备状态”区域，首行显示相机。圆点使用绿/红/灰三色，右侧显示“在线/离线/状态未知”，相机标识和错误详情通过辅助文字与 tooltip 展示。
