# 运行数据任务 ID 展示设计

## 目标

在“运行数据”面板中增加独立的“任务ID”指标卡，显示后端通过 `MillingPaths.task_id` 下发的任务号。

## 布局

- “任务ID”与“任务进度”放在同一行，补齐当前网格最后一行的空位。
- 顶部任务条继续保留，用于汇总任务状态、路径总数和标定状态。
- 顶部任务条不再重复任务 ID，左侧改为“路径总数 N 条”。

## 状态更新

- 未收到任务时，任务 ID 和路径总数均显示 `--`。
- 收到 `MillingPaths` 时，同时更新任务 ID、路径总数、运行状态和标定状态。
- 清空任务时，任务 ID、路径总数、运行状态和标定状态一起复位。

## 验收标准

- 演示任务 `task_id=9001` 时，“任务ID”卡显示 `9001`。
- 顶部任务条显示“路径总数 5 条”，不再重复显示 `9001`。
- 原有任务状态和标定状态显示逻辑保持不变。
